交通總覽

最省腦買法：關西市區用 ICOCA / KANSAI ONE PASS 刷卡，6/21 到金澤用 HOKURIKU One-way Ticket。不用買整張 JR Pass。

6/17 或 6/18 劃位任務：到大阪站或新大阪站 JR 綠色窗口，請站務員幫你和男友劃 6/21 大阪/新大阪 → 金澤的同一班相鄰座位。
英文：Osaka to Kanazawa, June 21, around noon. Seats together, please.

6/17神戶 → 大阪神戶站 / 三宮 / 元町 → 大阪站 → 天下茶屋到大阪站可順便劃金澤座位。

6/21大阪 → 金澤Thunderbird 到敦賀 → 北陸新幹線到金澤建議 11:00–14:00 出發。

二

神戶開場：抵達日本的第一天

高速船生田神社港邊夜景

07:35 台北飛大阪。

中午 關西機場出關，買 Bay Shuttle 外國旅客票。

下午 神戶機場 → Port Liner → 三宮/元町 → 神戶元町東急REI飯店。

傍晚 生田神社水占卜。

晚上 Harborland / Mosaic 港邊散步。

今日地圖

神戶元町東急REI 生田神社 Harborland

美食備案

南京町小吃
肉包、小籠包、可樂餅、胡麻團子。第一天不要吃太撐。
港邊便利商店甜點
買飲料、飯糰、小蛋糕去港邊坐一下，很有旅行開場感。

6/18
四

USJ 環球影城日

平日比較友善早到很重要高花費日

開園前 45–60 分鐘 抵達 USJ，進園後先看 Super Nintendo World 整理券。

上午 先衝最想玩的區域。

下午 逛商店、拍照、補設施。

晚上 視體力看夜景或早點回大阪休息，隔天是六週年和服日。

今日地圖

環球城站 USJ 西九条轉乘

美食備案

園內速食/套餐
方便快速，別為了吃排太久。
出園後烏龍麵 / 便利商店宵夜
隔天和服日，晚上不要太晚、不要太油膩。
6/19
五

京都和服六週年

和服明信片氛圍晚餐

08:30–09:00 大阪出發去京都。

10:30–11:30 祇園/清水寺/河原町附近換和服與髮型。

11:30–13:30 八坂庚申堂、二年坂三年坂、清水寺外圍。

13:30–14:30 午餐：蕎麥麵/烏龍麵/輕日式餐。

14:30–16:30 八坂神社、祇園白川、鴨川交換明信片＋小禮物。

16:30–17:30 還和服。

18:00–19:30 有氛圍的和牛壽喜燒/日式晚餐。

晚上 買小蛋糕回大阪，寫給 2027/6/19 的未來明信片。

今日地圖

京都河原町 八坂庚申堂 二年坂三年坂 祇園白川 鴨川 先斗町壽喜燒搜尋

美食備案

午餐：蕎麥麵/烏龍麵
穿和服吃最不狼狽，清爽又有日式感。
晚餐：高 CP 氛圍和牛壽喜燒
優先查富之上/富之上2號店、祇園牛禪、但馬屋四条河原町。想更有京都感就找先斗町。
小蛋糕
京都高島屋 B1 或河原町甜點區，買兩個小蛋糕回小宅吃。
